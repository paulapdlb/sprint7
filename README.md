# sprint7
Este proyecto forma parte del Sprint 7.

La aplicación desarrollada permite visualizar de forma dinámica un conjunto de datos de anuncios de venta de vehículos en Estados Unidos. Aunque el análisis de datos no es el foco principal del proyecto, se incluyen funcionalidades que permiten explorar variables relevantes mediante gráficos interactivos.

## Funcionalidades

- Visualización de histogramas para variables numéricas como el odómetro.
- Gráfico de dispersión entre kilometraje y precio, con color por condición del vehículo.
- Interfaz interactiva con casillas de verificación para activar visualizaciones.
- Lectura automática del archivo `vehicles_us.csv` desde la raíz del proyecto.

## Propósito del proyecto

Permitir la exploración visual de un conjunto de datos de anuncios de venta de coches en EE.UU., facilitando el análisis de variables como kilometraje, precio y condición del vehículo.

## Cómo usar la aplicación

1. Clona el repositorio y navega al directorio del proyecto.
2. Instala las dependencias:

```bash
pip install -r requirements.txt

3. Ejecuta la aplicación:
streamlit run app.py
